# STRIKE PROTOCOL（突袭协议）文档

## 项目概述

STRIKE PROTOCOL 是一款浏览器端第一人称战术射击游戏（FPS Web 应用），完整实现竞技爆破模式（炸弹安放/拆除）的玩法内核：Source 风格运动物理、弹道与后坐力系统、购买经济、回合制胜负、命中部位判定、Bot AI 对抗。全部美术资产（几何、材质、音效）均为程序化生成的原创内容。

**目标用户**: 单机玩家（含 AI 能力验证场景），本地人机对抗。

**范围边界（明确不做）**:
- 网络多人同步、反作弊
- 任何第三方版权资产（地图布局、模型、贴图、音效均原创）

**核心价值**:
- 玩法内核机制级还原：bhop/strafe 空中加速、固定序列后坐力、距离伤害衰减、连败经济补偿、C4 安放/拆除全流程
- 零外部资产依赖：所有内容程序化生成，构建即所得
- 单页应用交付：打开浏览器即可对局，支持在线预览

## 技术选型

| 类别 | 选择 | 理由 |
|------|------|------|
| 运行环境 | 浏览器（WebGL2） | 沙盒环境可直接构建与预览，验收成本最低 |
| 渲染 | Three.js r160+ | 成熟 WebGL2 抽象，InstancedMesh 支撑大量刷子几何 |
| 语言 | TypeScript 5（strict） | 实体/数值系统庞大，类型约束降低数值错误率 |
| 构建 | Vite 5 | 快速热更，静态产物单命令部署 |
| 角色物理 | 自研（AABB + Source 风格加速度模型） | bhop/strafe 依赖对加速度、摩擦的精确控制，现成物理引擎反而难以实现 |
| 弹道判定 | 自研 raycast（BVH 加速） | 需要与 hitbox 部位判定深度耦合 |
| Bot 寻路 | 网格 navmesh + A* | 单机 Bot 场景成本收益最优 |
| 音频 | WebAudio 程序化合成 | 原创音效零素材，空间音频用 PannerNode |
| 测试 | Vitest | 物理/经济/弹道数值全部可单测 |
| 地图格式 | 自研 JSON brush 定义 + 运行时构建 | Quake 风格刷子几何，人工可读可调 |

## 核心功能

### 运动系统（严格对标机制）
- **目的**: 复现竞技 FPS 的移动手感
- **描述**: 地面加速与摩擦、空中加速（air accelerate 与限速机制）、bhop 连跳与落地缓冲窗口、strafe jumping 增速、蹲（减速降低视角）与静走、蹲跳上箱、梯子攀爬、坠落伤害

### 武器与弹道
- **目的**: 复现射击手感与伤害模型
- **描述**: 每把枪独立的射速/换弹时间/弹匣容量/伤害/距离衰减/护甲穿透；固定序列后坐力 pattern（前 N 发可控轨迹）+ 散布（站/走/跑/跳四态惩罚）；爆头 4 倍率与部位倍率；穿墙衰减；投掷物（高爆、闪光、烟雾、燃烧）抛物线与反弹、区域效果

### 经济与回合制
- **目的**: 复现竞技爆破模式的策略层
- **描述**: 击杀奖励（按武器类型区分）、回合胜负奖励、连败补偿（1400 起步阶梯递增）、C4 爆炸/拆除奖励、金钱上限；冻结时间/购买时间/回合时间/C4 倒计时/拆弹时间（含拆弹钳减半）；MR15 先到 16 胜、半场换边；死亡掉武器、存活保留武器

### 命中与伤害
- **目的**: 复现命中判定精度
- **描述**: 头/胸/腹/臂/腿五段 hitbox 骨骼绑定，动画跟随；服务端权威式本地 raycast；护甲与头盔减伤公式；击杀反馈（hitmarker、击杀信息流）

### HUD 与界面
- **描述**: 血量护甲、弹药、金钱、回合计时、比分、雷达小地图（实时敌我位置）、买枪菜单（B 键分类购买）、计分板（Tab）、准星动态扩散、投掷物选择环

### Bot AI
- **描述**: A* 寻路 + 行为状态机（进攻 rush、守点、巡逻、交战走位、安弹守包、拆弹、经济局决策）；模拟人类瞄准（反应延迟、角速度上限、距离误差）；按经济状态自动购买

### 原创地图
- **描述**: 一张双爆破点地图：T 出生区、CT 出生区、两条 rush 通道、一条中央走廊、A/B 两个安放区、高低差与箱子掩体；程序化材质（混凝土、金属、木箱、沙地）；烘焙级静态光照 + AO

### 音效系统
- **描述**: WebAudio 合成枪声（按武器差异化）、脚步（材质区分）、C4 滴答与爆炸、换弹、命中反馈；基于距离衰减与 PannerNode 的空间化
