## 0. 定位与天花板声明

**产品定位**：浏览器端 5v5 爆破模式 FPS，单机 Bot 为主体验，PWA 可安装离线游玩。

**世界观顶级 FPS 的参照系**：
- CS2（Valve）——手感/竞技深度/生态的天花板
- Valorant（Riot）——角色能力+清晰视觉语言
- Critical Ops / Standoff 2——移动端 FPS 商业标杆

**浏览器平台的真实天花板**（务实声明，规划不吹牛）：
| 能做到世界级 | 受平台限制只能接近 | 明确放弃 |
| --- | --- | --- |
| 手感（后坐力/移动射击模型） | 3A 级画质（受 GPU/内存） | 128tick 权威服务器集群 |
| Bot AI 战术深度 | 大规模实时阴影 | 主机级反作弊 |
| 空间音频（WebAudio HRTF） | 4K 材质管线 | 百人同图 |
| PWA 秒开+离线 | — | — |
| 代码架构/测试覆盖（护城河） | — | — |

**总原则**：把有限的复杂度预算花在「玩家每秒都在感知的东西」上——手感、AI、音效、画面反馈；砍掉「每局只看一次的东西」。

## 2. 对标差距分析（按玩家感知排序）

### D1 手感与枪械物理（差距：大）——FPS 的灵魂
- 无**可学习的后坐力模式**（CS2 每把枪固定 spray curve，30 发弹道可背）。现在开火是纯随机散布。
- 无**移动射击精度模型**：counter-strafe 减速射击、跳跃/落地惩罚、移动开火散布惩罚——顶级 FPS 手感 80% 来自这套模型。
- 无**材质穿透**（穿木箱衰减、穿铁板减伤、穿人继续飞）。
- 无**命中分区模型**（头/胸/腹/腿伤害倍率与距离衰减；当前有爆头判定但无距离衰减曲线）。

### D2 角色与动画（差距：大）
- 人物动画是整段播放（跑/ idle），无**上下半身分层**（移动中开枪/换弹/投掷）、无受击方向反馈、死亡无布娃娃。
- 枪械 viewmodel 与人物动画脱节（换弹时人物不摸弹匣）。
- 角色无差异化（体型/装备/阵营识别全靠 tint 色相）。

### D3 渲染后处理与氛围（差距：中）
- 无后处理管线：无 bloom、SSAO、色彩分级（CS2 每张图有独立 color LUT）、雾体积。
- 粒子系统原始：无枪口火焰、弹壳抛射、血液喷溅、持久烟痕。
- 天空是静态渐变，无体积云/太阳光晕动态。

### D4 AI 战术深度（差距：中，刚补完个体层）
- 个体智能已达标（听觉/记忆/掩体/架点），缺**团队层**：协同进攻（rush/split/fake）、道具协同（烟封视线后突破）、报点共享（已有 radio 但 bot 消费浅）。
- 缺**经济决策**（eco/force/full-buy 影响买枪）。
- 架构债：947 行单文件状态机，加团队层前需重构为分模块决策管线。

### D5 音频空间化（差距：中）
- 无 HRTF（WebAudio 原生支持 `panningModel: 'HRTF'`，一行开启但需要调参验证）。
- 无声音遮挡（门后/墙后应闷声——已有穿墙低通但非几何驱动）。
- 无分区混响（室内混响 tail）。

### D6 内容生态（差距：大，但可延后）
- 无地图编辑器/分享码、无皮肤系统、生涯只有基础 K/D、bot 无 personality 差异化。

### D7 多人联机（差距：质变级）
- 当前纯单机。真多人 = WebSocket 权威服务器 + 客户端预测/和解 + 房间系统，工程量 ≈ 现有全部代码的 60-100%，且需要持续运营服务器。
- 浏览器替代方案：WebRTC P2P（1v1/2v2 可行，5v5 联机体验打折）。

### D8 工程护城河（优势项，需守住并扩大）
- 已有：确定性模拟（固定 tick+种子 RNG）、184 测试、清晰分层。
- 需补：bundle 分割（802KB→按场景懒加载）、物理/AI 移入 Web Worker、移动端渲染分级（iOS 内存墙）、E2E 回归脚本化。

## 3. 旗舰化路线图（六个征程）

### 征程 P0「手感内核」— 后坐力/移动射击/穿透（最高优先）
> 目标：闭眼能分辨这是不是 CS 系手感。这是所有后续视觉投入的前提。

| 项 | 内容 | 验收 |
| --- | --- | --- |
| P0-1 | 后坐力模式系统：每枪定义 spray curve（确定性弹道数组，30 发）+ recoil recovery + 散布随连发扩张 | 训练场墙弹痕呈可学习图案；单测确定性回归 |
| P0-2 | 移动射击精度：速度→散布映射曲线，counter-strafe（松键反向）0.2s 内散布收敛，跳跃/落地惩罚窗 | 静止/行走/奔跑/跳跃四种散布实测差异 ≥ CS 比例 |
| P0-3 | 命中分区+距离衰减：头 4x/胸 1x/腹 1.25x/腿 0.75x，伤害按距离线性衰减（每枪 range modifier） | 单测伤害表 + 实机爆头秒杀手感 |
| P0-4 | 材质穿透：raycast 命中 brush 读取材质→穿透力表（木>沙袋>混凝土>钢），穿射伤害衰减 | 穿木箱可击杀、穿钢墙不可 |
| P0-5 | 弹痕/曳光/命中反馈升级：贴花持久化 + 命中数字反馈（可选）+ 击杀图标 | 实机截图验收 |

### 征程 P1「视觉旗舰」— 后处理/动画/粒子（玩家第一眼）
| 项 | 内容 | 验收 |
| --- | --- | --- |
| P1-1 | 后处理管线：EffectComposer 接入 bloom（枪口/爆炸/C4）+ 每图色彩分级 LUT + 轻量 SSAO（可关） | 4 张图各有氛围；low 档自动关后处理 |
| P1-2 | 角色动画分层：上半身（开枪/换弹/投掷）独立于下半身（移动/跳蹲），Mixamo 骨骼 mask | 移动中开枪动画自然 |
| P1-3 | 死亡布娃娃：简单物理模拟（无 ragdoll 库，骨骼链衰减摆动） | 击杀观感提升实机验收 |
| P1-4 | 粒子系统旗舰化：枪口火焰 sprite 池、弹壳抛射（物理衰减）、血液喷溅、爆炸烟雾卷 | 实机截图 |
| P1-5 | 氛围：每图体积雾/动态天空（时间相位）、室内光池调优 | 4 图截图对比 |

### 征程 P2「AI 战术」— 从士兵到战队
| 项 | 内容 | 验收 |
| --- | --- | --- |
| P2-1 | 架构重构：bot.ts 拆为 感知/决策/移动/战斗 四模块，决策层引入可测的行为管线（不引重库，保持确定性单测） | 拆分后 184 测试全绿 |
| P2-2 | 团队战术层：回合开局选战术（rush/split/default/fake 按 map+经济），落点协同，道具协同（烟后突） | 观战录像评审 + 单测战术选择分布 |
| P2-3 | 经济决策：bot 按队伍钱池决定 eco/force/buy，影响买枪 | 经济局行为可辨识 |
| P2-4 | Personality：每 bot 固定性格（激进/稳健/狙击手偏好），瞄准误差模型差异化 | 同难度不同 bot 行为可分辨 |
| P2-5 | 报点消费深化：听到的声音进团队黑板，队友响应支援/回防 | 实机观感 |

### 征程 P3「听觉旗舰」— HRTF/遮挡/混响
| 项 | 内容 | 验收 |
| --- | --- | --- |
| P3-1 | HRTF 空间化开启+调参（PannerNode HRTF 模式，iOS 兼容测试） | 闭眼定位声源 |
| P3-2 | 几何驱动声音遮挡：raycast 到声源，材质决定低通量 | 门后脚步明显闷 |
| P3-3 | 分区混响（室内 ConvolverNode 短 tail） | 实机听感 |

### 征程 P4「内容与生态」
| 项 | 内容 | 验收 |
| --- | --- | --- |
| P4-1 | 地图编辑器 MVP：brush 摆放+分享码（base64 地图 JSON），社区地图可导入 | 用编辑器复刻一张 mini 图可玩 |
| P4-2 | 武器皮肤系统：贴图替换层 + 掉落/库存（纯本地） | 换肤实机 |
| P4-3 | 段位/生涯深化：段位图标+赛季统计+每局 MVP 评分 | UI 验收 |
| P4-4 | 成就系统 | UI 验收 |

### 征程 P5「工程护城河」
| 项 | 内容 | 验收 |
| --- | --- | --- |
| P5-1 | Bundle 分割：three.js/地图/编辑器按需 import()，首屏 <400KB | Pages 加载实测 |
| P5-2 | AI+物理 Worker 化：bot 决策移入 Worker（SharedArrayBuffer 状态同步或消息快照） | 主线程帧时间下降实测 |
| P5-3 | 移动端渲染分级：iOS 内存墙探测自动降档（贴图分辨率/阴影/粒子） | 老 iPhone 实机 30fps |
| P5-4 | E2E 回归脚本化：puppeteer 走查脚本入仓库（npm run e2e） | CI 可跑 |

### 征程 P6「多人联机」— ❌ 已取消
> 用户决策（2026-09-30）：不做多人，单机做到极致。本节保留决策理由备查。
> 原方案曾考虑：WebRTC P2P（1v1/2v2，零运维）与 WebSocket 权威服务器（5v5 64tick，需运维）。
> 取消理由：工程量≈现有代码 60-100%，且会稀释 Bot AI/手感/视觉的投入价值——单机体验才是本项目差异化所在。
